| Simbolo      | Nombre                           | Valor Proposicional |
| ------------ | -------------------------------- | ------------------- |
| $\land$      | Conjuncion (Y)                   |                     |
| $\lor$       | Disyuncion (O)                   |                     |
| $\neg$       | Negacion (NO)                    |                     |
| $\implies$   | Implicacion (SI... ENTONCES)     |                     |
| $\iff$       | Doble Implicacion (SI Y SOLO SI) |                     |
| $\oplus$     | OR Exclusivo (XOR)               |                     |
| $V$          | Verdadero (V)                    |                     |
| $F$          | Falso (F)                        |                     |
| **$\bot$**   | Indefinido                       |                     |
| $\forall$    | Para todos                       |                     |
| $\exists$    | Existe                           |                     |
| $\uparrow$   | Nand (NO Y)                      |                     |
| $\downarrow$ | Nor (NO O)                       |                     |
| $\equiv$     | Equivalencia (IGUAL A)           |                     |
| $\land L$    | Y-luego (CAND)                   |                     |
| $\land L$    | O-luego (COR)                    |                     |
